### 大堡礁活动详情（10.5）

行程单写的是「太阳恋人号飞去船回」，费用表为「**大冒险号：飞去船回**」——以实际预订为准。活动介绍中有两种常见方案：

#### 方案 A：飞去绿岛 → 船去外堡礁 → 船回凯恩斯

| 时间 | 事项 |
|------|------|
| 08:30 | 自行前往办理登机地点 |
| 08:35 | 开始 check in |
| 09:20 | 乘直升机飞往绿岛 |
| 09:40 | 抵达绿岛，自由活动 |
| 11:20 | 乘游船开往外堡礁平台 |
| 12:15 | 抵达外堡礁平台 |
| 13:00 | 澳式烧烤自助午餐，餐后自由活动 |
| 15:30 | 乘游船返回凯恩斯 |
| 17:30 | 抵达凯恩斯码头 |

- 直升机机场：2 Pier Point Road, Cairns Marina（出发 09:20）

#### 方案 B：船去绿岛 → 船去外堡礁 → 飞回凯恩斯

| 时间 | 事项 |
|------|------|
| 07:30 | 自行前往码头集合 |
| 08:30 | 乘游船前往绿岛 |
| 09:15 | 抵达绿岛，约 2 小时自由活动 |
| 11:20 | 乘游船前往外堡礁 |
| 12:15 | 抵达外堡礁平台 |
| 13:00 | 烧烤自助午餐，餐后自由活动 |
| 15:15 | 乘直升机飞回凯恩斯 |
| 15:40 | 抵达凯恩斯，行程结束 |

- 码头：Reef Fleet Terminal, Spence St 1, Cairns QLD 4870（出发 08:30）

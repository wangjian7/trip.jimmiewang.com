## 航班价格追踪（0002_flight_prices.sql，待创建）

### 设计要点

- **两个时间维度分开**：`travel_date` 是固定的出发日（如 2026-09-30）；`scrape_date + slot` 是观测时间点（哪天上午/下午看的价）。价格曲线 = 固定 travel_date 的航班，按观测时间排列。
- **三层结构**：监控配置 → 抓取批次 → 航班报价，一次抓取产生一条 run + 多条 quote。
- **同一航班跨批次比价**靠 `flight_fingerprint`，不靠 run_id。
- **价格存整数元（CNY）**，避免浮点误差；口径为东航官网直销价。

```
flight_watches（盯哪条航线、哪个出发日）
    └── flight_scrape_runs（每天 am/pm 各一次抓取）
            └── flight_quotes（该次抓到的每个航班及价格）
```

### flight_watches — 监控配置

一条记录 = 一个监控任务（航线 + 固定出发日 + 筛选条件）。

```sql
CREATE TABLE IF NOT EXISTS flight_watches (
  id TEXT PRIMARY KEY NOT NULL,              -- 如 fw-sha-bne-20260930
  trip_slug TEXT,                            -- 可选，关联 trips.slug
  label TEXT NOT NULL,                       -- 「9.30 上海→布里斯班 直飞」

  origin_code TEXT NOT NULL,                 -- SHA（城市码，含 PVG/SHA 两场）
  dest_code TEXT NOT NULL,                   -- BNE
  travel_date TEXT NOT NULL,                 -- ★ 固定出发日 2026-09-30

  direct_only INTEGER NOT NULL DEFAULT 1,    -- 1=只关注直飞
  cabin TEXT NOT NULL DEFAULT 'economy',     -- 关注舱位
  adult_count INTEGER NOT NULL DEFAULT 1,

  source TEXT NOT NULL DEFAULT 'ceair',      -- 数据源标识（对应抓取端适配器）
  source_url TEXT,                           -- 人工覆盖 URL；为空时由适配器从上方参数生成
  enabled INTEGER NOT NULL DEFAULT 1,        -- 1=参与定时抓取

  created_at TEXT NOT NULL,
  updated_at TEXT NOT NULL,

  UNIQUE(origin_code, dest_code, travel_date, cabin, direct_only, source)
);

CREATE INDEX IF NOT EXISTS idx_flight_watches_trip
  ON flight_watches(trip_slug);
```

首条数据示例：

| 字段 | 值 |
|------|-----|
| id | `fw-sha-bne-20260930` |
| trip_slug | `au-2026-09-30` |
| travel_date | `2026-09-30` |
| source_url | `https://www.ceair.com/zh/cny/shopping/oneway/SHA,PVG-BNE/2026-09-30` |

### flight_scrape_runs — 抓取批次

一条记录 = 一次观测（某天的上午或下午）。

```sql
CREATE TABLE IF NOT EXISTS flight_scrape_runs (
  id TEXT PRIMARY KEY NOT NULL,
  watch_id TEXT NOT NULL,

  scrape_date TEXT NOT NULL,                 -- ★ 观测日（北京时间）2026-07-07
  slot TEXT NOT NULL CHECK (slot IN ('am', 'pm')),

  started_at TEXT NOT NULL,                  -- ISO 时间
  finished_at TEXT,
  status TEXT NOT NULL
    CHECK (status IN ('running', 'success', 'failed')),
  error_message TEXT,                        -- 失败原因（超时/被拦/解析失败）
  requested_url TEXT,                        -- 本次实际请求的 URL（审计/排查改版与配置漂移）

  flights_found INTEGER NOT NULL DEFAULT 0,  -- 本次抓到的航班数
  min_price_cny INTEGER,                     -- 本次直飞最低价，列表页快速展示用

  FOREIGN KEY (watch_id) REFERENCES flight_watches(id),
  UNIQUE(watch_id, scrape_date, slot)        -- 同一天同时段只保留一次
);

CREATE INDEX IF NOT EXISTS idx_flight_scrape_runs_watch
  ON flight_scrape_runs(watch_id, scrape_date);
```

调度约定（北京时间）：

| slot | Cron（UTC） | 实际执行 |
|------|------------|---------|
| am | `0 1 * * *` | 09:00 |
| pm | `0 7 * * *` | 15:00 |

### flight_quotes — 航班报价

一条记录 = 某次抓取里看到的一个航班方案及当时价格。

```sql
CREATE TABLE IF NOT EXISTS flight_quotes (
  id TEXT PRIMARY KEY NOT NULL,
  run_id TEXT NOT NULL,
  watch_id TEXT NOT NULL,                    -- 冗余，免 JOIN 直查

  -- 航班身份（跨批次串联同一航班）
  flight_fingerprint TEXT NOT NULL,          -- 见下方生成规则
  flight_numbers TEXT NOT NULL,              -- MU715；中转用 + 连接：MU737+QF620
  airline_name TEXT,                         -- 中国东方航空
  is_direct INTEGER NOT NULL DEFAULT 1,

  travel_date TEXT NOT NULL,                 -- 冗余，查询方便
  depart_at TEXT NOT NULL,                   -- 21:15（当地时间）
  arrive_at TEXT NOT NULL,                   -- 09:00+1
  duration_minutes INTEGER,                  -- 585（9h45m）
  aircraft TEXT,                             -- 空客332(宽)

  -- 价格（整数元，CNY）
  price_economy_cny INTEGER,                 -- 经济舱 7040
  price_premium_cny INTEGER,                 -- 超级经济舱（页面为 — 时存 NULL）
  price_business_cny INTEGER,                -- 公务/头等 43180

  scraped_at TEXT NOT NULL,                  -- ISO 时间

  FOREIGN KEY (run_id) REFERENCES flight_scrape_runs(id),
  FOREIGN KEY (watch_id) REFERENCES flight_watches(id),
  UNIQUE(run_id, flight_fingerprint)         -- 同次抓取同航班不重复
);

CREATE INDEX IF NOT EXISTS idx_flight_quotes_trend
  ON flight_quotes(flight_fingerprint, scraped_at);
CREATE INDEX IF NOT EXISTS idx_flight_quotes_watch
  ON flight_quotes(watch_id, travel_date, scraped_at);
```

### 抓取 URL 策略（应对官网改版）

**原则：URL 是派生数据，结构化参数才是真相。**

东航当前 URL 与表字段的对应：

```
https://www.ceair.com/zh/cny/shopping/oneway/SHA,PVG-BNE/2026-09-30
                      └语言币种┘         └单程┘ └出发-到达┘ └出发日┘
```

| URL 片段 | 来源 |
|----------|------|
| `zh/cny`、`oneway` | 抓取端适配器写死（实现细节，非业务参数） |
| `SHA,PVG` | `origin_code='SHA'` + 适配器内「城市码→机场列表」字典 |
| `BNE` | `dest_code` |
| `2026-09-30` | `travel_date` |

抓取端取 URL 的逻辑：

```
watch.source_url 非空 → 直接使用（人工覆盖通道）
watch.source_url 为空 → 按 watch.source 选适配器，从结构化参数拼 URL
```

改版/换源的处理方式：

- **东航路径小改**：只改 `ceair` 适配器的 URL builder 与解析器，数据不动。
- **应急**：来不及改代码时，直接 UPDATE `flight_watches.source_url` 填新地址。
- **彻底换数据源**：新增 `source='xxx'` 的 watch + 新适配器；新旧数据靠 `watch_id` 隔离，历史曲线保留。
- 每次抓取把实际请求地址记入 `flight_scrape_runs.requested_url`，便于事后审计「这批价格从哪抓的」。

### flight_fingerprint 生成规则

```
{travel_date}|{origin_code}|{dest_code}|{flight_numbers}|{depart_at}
```

示例：`2026-09-30|SHA|BNE|MU715|21:15`

规则说明：

- 用监控配置里的城市码（SHA），不用实际起飞机场码（PVG），避免同一航班因机场标注差异断链。
- 中转方案的 flight_numbers 按航段顺序用 `+` 连接（如 `MU737+QF620`），起飞时刻取第一段。
- 同一航班若官网调整起飞时刻（如 21:15 → 21:30），fingerprint 会变化、曲线断开——属于可接受行为，因为时刻变更后本质上是新的销售方案。

## 常用查询

MU715 完整价格走势（画曲线用）：

```sql
SELECT r.scrape_date, r.slot, q.price_economy_cny, q.scraped_at
FROM flight_quotes q
JOIN flight_scrape_runs r ON r.id = q.run_id
WHERE q.flight_fingerprint = '2026-09-30|SHA|BNE|MU715|21:15'
ORDER BY q.scraped_at;
```

相对上一次观测的涨跌：

```sql
SELECT scrape_date, slot, price_economy_cny,
       price_economy_cny - LAG(price_economy_cny) OVER (ORDER BY scraped_at) AS delta
FROM (
  SELECT r.scrape_date, r.slot, q.price_economy_cny, q.scraped_at
  FROM flight_quotes q
  JOIN flight_scrape_runs r ON r.id = q.run_id
  WHERE q.flight_fingerprint = '2026-09-30|SHA|BNE|MU715|21:15'
);
```

某观测日上午 vs 下午：

```sql
SELECT r.scrape_date,
       MAX(CASE WHEN r.slot = 'am' THEN q.price_economy_cny END) AS am_price,
       MAX(CASE WHEN r.slot = 'pm' THEN q.price_economy_cny END) AS pm_price
FROM flight_quotes q
JOIN flight_scrape_runs r ON r.id = q.run_id
WHERE q.flight_numbers = 'MU715'
GROUP BY r.scrape_date
ORDER BY r.scrape_date;
```

每个航班的最新报价（列表页用）：

```sql
SELECT q.*
FROM flight_quotes q
JOIN (
  SELECT flight_fingerprint, MAX(scraped_at) AS max_at
  FROM flight_quotes
  WHERE watch_id = 'fw-sha-bne-20260930'
  GROUP BY flight_fingerprint
) latest ON latest.flight_fingerprint = q.flight_fingerprint
        AND latest.max_at = q.scraped_at;
```
